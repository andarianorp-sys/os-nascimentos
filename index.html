Como hospedar gratuitamente no GitHub Pages:

  1. Crie um repositório público no GitHub com o nome nascimento-app.
  2. Faça upload deste arquivo renomeado exatamente como index.html.
  3. Acesse as Settings do repositório > menu Pages.
  4. Em Source, selecione a branch main (ou master) e salve.
  5. Seu aplicativo estará online em poucos segundos no seu link exclusivo!
